# Field suggestions validation - v0.2.4

The fixes were published first as v0.2.3, with only its signed APK attached.
This follow-up adds contextual field suggestions to the same annotation model.

## Detection and interaction

PDFBox reads an independent immutable snapshot. Eligible empty text and unsigned
signature widgets are detected across nested fields and pages, including missing
widget page references resolved through page annotations. Hidden, protected,
filled, password, invalid and outside-page fields are skipped. Coordinates use
the displayed CropBox after 0/90/180/270 degree rotations.

Printed detection conservatively pairs recognized English labels with empty
vector outlines or horizontal lines. Occupied text, images, filled shapes and
foreign annotations prevent guesses. Widget geometry takes precedence even when
a widget is ineligible, so a printed border cannot bypass its restrictions.
Explicit clipping suppresses printed guesses for that page. Complexity/candidate
limits avoid unbounded hint processing. No OCR or detection of every printed
form is claimed.

Hand shows small Fill/Sign hints only during editing. Tapping Fill opens the
keyboard and inline text at the detected box. Tapping Sign fits the selected
signature or opens capture; a newly captured signature is placed into the
requested box. Hints disappear under the added object and return after deletion,
undo or discard. Reading remains uncluttered. These are editable annotations;
AcroForm data values and cryptographic signatures are not changed. Long text can
expand beyond its initial field using the standard editable text-box behavior.

## Evidence

- Nine detector regressions passed initially in both JVM variants. Two additional
  tests reproduced false hints from clipped geometry before the fail-closed fix.
- Thirteen placement tests cover text fitting, arbitrary signature origins,
  aspect ratio, degenerate inputs, occupied fields and ink segment intersections.
- Three initial UI tests failed for missing suggestions before implementation.
- Five focused UI tests passed for hidden reading hints, actual touch-to-type,
  empty text cancellation, stored signatures, capture-and-place, undo and discard.
- A real widget fixture passed detection through the production Activity, inline
  typing, explicit source save, annotation extraction and reopening. Typing left
  source bytes unchanged; reopening left the explicitly saved bytes unchanged.
- VM integration covers page order, field coordinates, private draft recovery,
  editable export and discard without source changes.
- Two resource-ownership regressions reproduced leaked PDF copies when canceled
  during reading or between IO completion and caller resumption. Both passed
  after an outer NonCancellable ownership scope restored caller cancellation for
  reads and retained reliable cleanup. A reader-error cleanup control also passes.
- Both JVM variants currently pass 155 tests.
- Not yet run: the full instrumented suite on this commit, lint, optimized
  release size, and signed upgrade checks. v0.2.4 has not been tagged or
  published.

## Scope

Runtime checks use an isolated API 35 arm64 emulator, not a physical device or
API 26. No dependency, app network permission or network code was added. The
existing release key is retained; releases contain the APK only.
